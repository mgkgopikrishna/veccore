# VecCore

Changing embedding model invalidates every vector you have stored — and nothing in a
typical RAG stack notices. This demo lets you drive a migration yourself: backfill,
watch the incomplete space refuse to serve, measure the retrieval drift, then cut over
or watch a strict gate refuse.

Runs on CPU. No API key, no model download.

Source: https://github.com/mgkgopikrishna/veccore
